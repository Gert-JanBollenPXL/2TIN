SNMP Trap

A trap is:
Unsolicited
Fire-and-forget
UDP-based
No acknowledgement required
The device sends the message once and assumes it arrived.


SNMP Inform

An inform is similar to a trap, but more reliable.
Differences:
Requires acknowledgement (ACK)
Device retries if no response
More reliable than traps
Slightly more bandwidth/CPU usage
