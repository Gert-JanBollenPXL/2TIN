! ============================================================
! PART 1: Configure SNMP
! ============================================================
conf t 

! SNMPv2 community strings
snmp-server community SNMP-RO ro
snmp-server community SNMP-RW rw

! SNMP server (Zabbix)
snmp-server host 10.199.64.67 version 2c SNMP-RO

! SNMP notifications
snmp-server enable traps snmp authentication
snmp-server enable traps config

! Syslog trap messages
snmp-server enable traps syslog

end

----------------------------------------------------------------------------

show snmp
show snmp community
show snmp host

! ============================================================
! PART 3a: Secure SNMP
! ============================================================
R01+R02+SW01+SW02:

conf t

! ACL die alleen Zabbix server toelaat voor requests
ip access-list standard ACL-SNMP
 permit host 10.199.64.67
 deny any

! Requests community strings (met ACL)
snmp-server community SNMP-RO ro ACL-SNMP
snmp-server community SNMP-RW rw ACL-SNMP

! Aparte community string voor notifications/traps
! (andere naam dan SNMP-RO/SNMP-RW!)
snmp-server community SNMP-TRAP ro
snmp-server host 10.199.64.67 version 2c SNMP-TRAP

end

-----------------------------------------------------------------------------
Controleren: 
show snmp community
show snmp host

R01 + R02 + SW01 + SW02:
"requests community strings are not identical to notifications community strings"
Oude SNMP-RO trap entry verwijderen:

no snmp-server host 10.199.64.67 version 2c SNMP-RO
end

! ============================================================
! PART 4: SNMPv3
! ============================================================
conf t

! SNMPv3 view (toegang tot alle OIDs)
snmp-server view SNMP-VIEW iso included

! SNMPv3 group met read access op de view
snmp-server group SNMP-GROUP v3 priv read SNMP-VIEW

! SNMPv3 gebruiker
snmp-server user SNMP-USER SNMP-GROUP v3 auth sha cisco123 priv aes 128 cisco123

end


ZABBIX:
Klik op LAB-RA04-C01-R01 → Edit → onder Interfaces klik Add → kies SNMP en vul in:
	- IP address: 172.16.4.2
	- Port: 161
	- SNMP version: SNMPv3
	- Context name: (leeg laten)
	- Security name: SNMP-USER
	- Security level: authPriv
	- Auth protocol: SHA
	- Auth passphrase: cisco123
	- Priv protocol: AES128
	- Priv passphrase: cisco123
